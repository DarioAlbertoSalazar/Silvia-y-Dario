# Silvia & Dario · 25.09.2027

Invitación digital para la boda de Silvia y Dario.

- **Ceremonia:** 17:30 h · Parroquia San José del Barrial
- **Recepción:** 20:00 h · Chalet Barrial
- **Vestimenta:** formal
- **Mesa de regalos:** lluvia de sobres

## Contenido

Es una sola página (`index.html`) sin dependencias que instalar. Incluye cuenta regresiva, itinerario con enlaces a Google Maps, botón para guardar en Google Calendar, animaciones al hacer scroll y modo oscuro automático.

## Cómo verla

Abre `index.html` en cualquier navegador.

Para publicarla con GitHub Pages: **Settings → Pages → Branch: `main` / root → Save**. La invitación queda en `https://<usuario>.github.io/<repositorio>/`.

## Cómo editar

- **Nombres y fecha:** el objeto `BODA` al inicio del `<script>`.
- **Colores:** las variables del bloque `:root` al inicio del `<style>`.
